Static, responsive portfolio built from the supplied CV and project details.

- About
- Experience
- Skills
- Projects
- Certifications

## Included SEO foundation
- Unique `<title>` and meta description per page
- Canonical URLs
- Open Graph + Twitter metadata
- Semantic HTML and crawlable navigation links
- Descriptive image alt text
- `robots.txt`
- `sitemap.xml`
- JSON-LD `ProfilePage` + `Person`
- Responsive design
- Optimized JPG + WebP portrait
- Resume PDF

## Deploy to Vercel
This is a plain static site, so no build command is required.

### GitHub
1. Create a repository.
2. Upload all files/folders in this directory.
3. Commit and push.

### Vercel
1. Import the GitHub repository into Vercel.
2. Framework preset: Other / static.
3. Build command: leave blank.
4. Output directory: `.`
5. Deploy.
